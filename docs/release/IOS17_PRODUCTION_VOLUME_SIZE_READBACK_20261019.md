# Size-only database/object-store recovery qualification

The running production PostgreSQL and MinIO containers are bound to their expected persistent Compose volumes and expose backup/restore binaries, independently verified by the no-write run 39305951080. Before creating any backup or deploying code, this owner-only read-only metadata check records **only aggregate `du -sk` sizes** for the two mounted data paths and the host's free capacity. It refuses malformed output, duplicate paths and negative sizes; it does not read SQL rows or object keys, extract object content, run a DB backup or write to production volumes. Local stateful storage being large may require independently approved off-host encrypted backup custody; a green size estimate never authorizes cutover.
